## Featured Projects

### 🛰️ [CloudThreat Atlas](https://github.com/meneeses/cloudthreat-atlas)
A local-first, read-only cloud security workspace that turns Azure resources, identities, network exposure and permissions into an explainable attack graph, with point-in-time snapshots, findings and what-if remediation. Ships as a single Go binary with an embedded React dashboard. **[Live demo →](https://meneeses.github.io/cloudthreat-atlas/)**

**Go · React · TypeScript · SQLite · Azure**

### 🛡️ [Sentinela: Secure User Management](https://github.com/meneeses/gestao-usuarios)
A full-stack user-management app demonstrating JWT authentication, role-based authorization, secure defaults and reproducible local setup, with API docs, automated tests and end-to-end browser coverage.

**React · TypeScript · Express · Prisma · Playwright · Vitest**

### ⚙️ [CI/CD Reference Project](https://github.com/meneeses/ci-cd-bot-project)
A Node.js reference pipeline with automated tests, Docker image publishing, GitHub Actions and deployment notifications.

**Node.js · Jest · Docker · GitHub Actions**

### 🍦 ICone: SaaS ERP for gelato producers (private)
Multi-tenant SaaS ERP covering recipe balancing, formula reverse-engineering, nutrition labeling, subscriptions and a B2B marketplace. As lead engineer I designed the architecture and built it on .NET 10, Next.js and PostgreSQL, including the Supabase → Neon migration, tenant isolation with row-level security and reliable payment flows. The code is private; happy to walk through the architecture in an interview.

**.NET · Next.js · React · PostgreSQL · Redis · Azure**
